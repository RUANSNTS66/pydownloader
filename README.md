# PyDownloader

A simple and practical media downloader built with Python and [yt-dlp](https://github.com/yt-dlp/yt-dlp).

PyDownloader allows users to download videos and playlists from supported platforms, with options to choose the download location and extract audio in MP3 format.

## Features

-  **Video Downloads** — Download videos in the best available quality.
-  **MP3 Audio** — Extract audio and save it as MP3.
-  **Custom Download Location** — Choose where your files will be saved.
-  **Playlist Support** — Download multiple videos from a playlist.
-  **Simple Interface** — Easy-to-use workflow for downloading media.
-  **Python-Based** — Built with Python and yt-dlp.

## Technologies

- Python
- yt-dlp
- FFmpeg

## Requirements

- Python 3.10 or later recommended.
- FFmpeg installed and available in your system PATH.
- Internet connection.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/RUANSNTS66/PyDownloader.git
   ```

2. Navigate to the project folder:

   ```bash
   cd PyDownloader
   ```

3. Install the dependencies:

   ```bash
   pip install yt-dlp
   ```

4. Run the application:

   ```bash
   python pydow-0.04.py
   ```

   Replace `main.py` with the actual entry-point filename if needed.

## How to Use

1. Run the application.
2. Select the download destination.
3. Paste the video or playlist URL.
4. Choose the desired download option.
5. Wait for the download to finish.
